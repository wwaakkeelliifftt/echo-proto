## 📋 **Текущая задача**

Реализовать функциональность удаления эпизодов из памяти устройства по нажатию на кнопку `btnPlayback` (с иконкой корзины) в `DownloadsFragment.kt`.

## 🎯 **Контекст проблемы**

### **Текущее состояние:**
- **Кнопки `btnFavorite` и `btnQueue`** - опциональные, их отображение работает корректно
- **Кнопка `btnPlayback`** - постоянная, всегда видна на экране загрузок
- **Текущая реализация `btnPlayback`** - заглушка с тостом
- **Целевая функциональность** - удаление эпизода из памяти устройства

### **Опциональность кнопок:**
- Пользователь может включать/выключать отображение кнопок
- Необходимо учитывать это в реализации, чтобы избежать ошибок
- `btnPlayback` в режиме DELETE всегда видна на экране загрузок

## ⚠️ **Риски и митигации**

### **Риск 1: Опциональность кнопок**
- **Проблема:** NPE при обращении к кнопке, которая может быть скрыта
- **Митигация:** Проверка видимости и null-безопасность

### **Риск 2: Инъекция зависимостей**
- **Проблема:** Конфликт с существующей DI конфигурацией
- **Митигация:** Тщательная проверка текущей архитектуры

### **Риск 3: Асинхронность удаления**
- **Проблема:** UI не обновляется после удаления
- **Митигация:** Использование Flow/LiveData для реактивных обновлений
