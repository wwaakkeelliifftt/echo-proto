# Отчет: Система динамической настройки интерфейса (Episode Display Settings)

## 🎯 Цель работы
Создание гибкой системы настройки отображения карточек эпизодов, позволяющей пользователю персонализировать плотность контента и видимость элементов независимо для каждого из 4-х основных экранов приложения (**Feed, Queue, Channels, Downloads**).

## 🏗️ Архитектурные решения

### 1. Ядро настроек (SettingsManager)
- **Технологии**: Hilt (Singleton), SharedPreferences (`androidx.preference`), Kotlin Coroutines `StateFlow`.
- **Функционал**: Централизованное хранилище настроек. Каждый экран идентифицируется уникальным `screenKey`.
- **Реактивность**: Использование `getOptionsFlow(screenKey)` позволяет ViewModels "подписываться" на изменения настроек и мгновенно обновлять UI.

### 2. Универсальный адаптер (EpisodeFeedAdapterV2)
- **Производительность**: Внедрена поддержка `PAYLOAD_DISPLAY_OPTIONS`. При смене настроек перерисовываются только затронутые элементы (без мерцания и полной перезагрузки списка).
- **Гибкая верстка**: Реализована поддержка всех флагов из `EpisodeDisplayOptions`:
    - `showImageCover`: Видимость обложки.
    - `showMetadata`: Видимость строки параметров (длительность/размер).
    - `isSpaceOptimized`: Режим "Ultra Compact", при котором обложка уменьшается с 52dp до 40dp, а пустая область метаданных полностью удаляется (`GONE`).
    - `showDateHeaders`: Возможность превратить ленту со стик-хедерами в сплошной список.
    - `isCompactMode`: Уменьшение внутренних отступов карточки (padding).
- **Glide Integration**: Внедрена загрузка обложек через расширение `loadEpisodeImage`.

## 🎨 Интерфейс и UX

### DisplaySettingsBottomSheet
- **Фиксированная структура**: Использование `LinearLayout` с `weight` позволило закрепить "шапку" (превью) и "подвал" (кнопки), сделав центральную часть со свитчами скроллируемой.
- **Live Preview**: Верхняя часть шторки содержит эталонный заголовок и карточку, которые в реальном времени показывают результат переключения настроек.
- **Интеллектуальные опции**: 
    - Свитч "Optimize Space" визуально вложен в группу метаданных и появляется только при их отключении.
    - Группа выделена золотой рамкой в стиле **Nocturne Gold**.
- **Управление контекстом**: Добавлен акцентный выпадающий список для выбора экрана, настройки которого редактируются в данный момент.
- **Кнопки управления**: 
    - **Reset**: Сброс настроек текущего экрана к значениям по умолчанию.
    - **Apply Settings**: Сохранение и мгновенное применение изменений к активному списку.
- **Поведение**: Автоматическое раскрытие шторки на весь экран при запуске.

## 🛠️ Исправления и стабильность
- **Crash Fix**: Устранена ошибка `IndexOutOfBoundsException` в `DiffUtil` за счет работы со снимков списка элементов.
- **Hilt Compatibility**: Шторка переведена на работу через `newInstance` и `arguments`, что решило проблему с конструкторами в Dagger.
- **Theme Fix**: Добавлены необходимые стили в `themes.xml`, предотвращающие падение `TextInputLayout` при инфлейте в BottomSheet.
- **Search Support**: Логика включения/выключения хедеров интегрирована с механизмом `submitFeedItems`, что гарантирует корректную работу поиска при любой структуре списка.

## 🚀 Планы на будущее
- **Повсеместная имплементация**: Перевод всех экранов со списками эпизодов (Queue, Channels, Downloads) на `EpisodeFeedAdapterV2` для унификации UI и поддержки созданной системы настроек.
- **Интеграция настроек**: Подключение соответствующих `ViewModel` к `SettingsManager` для автоматического применения параметров на каждом экране.
